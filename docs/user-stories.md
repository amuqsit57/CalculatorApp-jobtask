# User Stories with Acceptance Criteria

How the app helps them get the job done. Each story names the job it serves and has acceptance criteria and a status (Implemented or Not implemented).

Format: "As a [role], I want [capability], so that [benefit]."

Acceptance criteria format: "Given [starting state], when [action], then [observable result]." Cover the normal case, invalid input, boundary values, very large or very small numbers, and carrying on after a result or an error.
